A React.js based application for creating and visualising web app colour themes, using the Tailwind CSS colour palette. A useful way to create colour themes for content, quickly and easily.

The user can use the theme controls panel to update the mock preview colour theme in real time.

Colours are also visually displayed in the theme controls panel, along with their hex value, and equivalent Tailwind CSS colour class.

The user can copy these data values (in a JSON format) to their clipboard with the 'Copy Theme' button, for use in their own projects.
